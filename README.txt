IT Elect 201 - Identification Quiz

FILES:
- index.html  = website structure
- style.css   = website design
- script.js   = quiz questions and JavaScript logic

HOW TO OPEN:
1. Open index.html in Chrome or Edge.
2. Type your answer.
3. Click Check Answer.
4. Repeat Quiz randomizes the question order.

HOW TO ADD A QUESTION:
Open script.js and add another object inside questionBank.

Example:
{
    question: "What is a blueprint for creating objects?",
    answers: [
        "class"
    ]
},
